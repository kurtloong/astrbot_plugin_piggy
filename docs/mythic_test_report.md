## 验证结论

- 六组主题小怪和三名 Boss 均进入同一总回合计时；每组至少包含坦克、输出、治疗。
- 小怪进度达到 100% 后才算完成。
- 每次 ADD 均记录实际触发玩家、小猪、阶段和回合。
- 所有常规小怪均来自猪圈；ADD 也只从当前副本的小怪池抽取。
- 整趟先进行一次 30% ADD 判定，命中后最多出现 1–2 次。
- 测试模式不写入钥石、奖励或排行榜。
